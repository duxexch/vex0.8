## 📊 Key Performance Indicators (KPIs)

1. **Search Indexing**: 100% of canonical public routes indexed in Google & Bing Search Console.
2. **Crawler Health**: 0 crawl errors, 0 soft-404s, 0 inadvertent admin indexations.
3. **AI Eligibility**: Valid Schema.org structured data on 100% of indexable routes.
4. **Core Web Vitals**: Pass LCP (< 2.5s), INP (< 200ms), and CLS (< 0.1).
